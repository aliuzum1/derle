# Gerçek Mini-PaaS Sunucusu

Bu proje; arkada gerçek `git clone`, `npm install` ve build işlemleri yürüten Node.js tabanlı bir platform sunucusudur.

## Nasıl Çalıştırılır?
1. `npm install` komutunu çalıştırın.
2. `npm start` ile sunucuyu başlatın.
3. Tarayıcınızdan `http://localhost:3000` adresine gidin.
